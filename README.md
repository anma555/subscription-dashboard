# サブスク契約ダッシュボード

モバイルアプリのサブスクリプション契約状況（有効サブスク数・新規・解約・MRR・トライアル転換）を見るダッシュボードです。
データはサーバ起動時に生成するダミーデータで、実在のアプリの数字ではありません。

## 起動方法

Node.js 18 以上が必要です。外部パッケージは使っていないので `npm install` は不要です。

```bash
npm start
```

ブラウザで http://localhost:3000 を開きます。

ポートを変えるときは `PORT` を指定します。

```bash
PORT=8080 npm start
```

## 画面でできること

### ダッシュボード（`/` または `/#dashboard`）

- **絞り込み**：期間（30日・90日・180日・1年）、OS（すべて・iOS・Android）、プラン（すべて・月額・年額）。切り替えると数字・グラフ・表がすべて連動します。
- **指標カード**：有効サブスク数、新規、解約（月次解約率つき）、MRR（ARPUつき）、トライアル転換率。前の期間からの変化を、良い変化は緑・悪い変化は赤で表示します。
- **グラフ**：MRR推移（イベントの縦線と一覧つき）、新規と解約、トライアル開始と有料転換、有効サブスクの内訳。マウスを乗せると詳細が出ます。180日と1年では棒グラフを週次にまとめます。
- **セグメント別の表**：OS×プランごとの有効サブスク・新規・解約・解約率・MRR・構成比・転換率。

### 生データ（`/#raw`）

画面上部の「生データ」タブで、サーバが生成した行をそのまま表で見られます。

- 「日次データ」と「イベント」を切り替えられます。
- 上部の期間・OS・プランの絞り込みがそのまま効きます。生データでは「全期間」も選べます。
- 列名をクリックすると並べ替え、もう一度クリックすると逆順になります。
- 「日付で検索」に `2026-08` などを入れると、その日付を含む行だけに絞れます（イベントではイベント名でも検索できます）。
- 表示件数は 50／100／500 件から選べ、ページ送りができます。
- 「CSVをダウンロード」で、いま表示している条件の行を CSV で保存できます（Excel でも文字化けしないよう BOM つき）。

## ダミーデータ

### 起動するたびに変わる

`npm start` するたびに乱数のシードが変わり、データ全体が作り直されます。
起動時のログと画面右上の「seed」に、そのときのシードが表示されます。

```
サブスク契約ダッシュボード: http://localhost:3000
ダミーデータ: seed=1728497596  2024-10-31〜2026-10-31  2924行 / イベント15件
同じデータを再現するには: SEED=1728497596 npm start
```

デモで同じ画面を再現したいときは、そのシードを指定して起動します。

```bash
SEED=1728497596 npm start
```

データの期間は「起動した日の前日」までの2年分（731日）です。

### 毎回ランダムに変わる要素

| 要素 | 内容 |
| --- | --- |
| ベースの水準 | OS×プランごとの初期有効サブスク数（±20%）、トライアル流入（±15%）、転換率（±4pt）、解約率（-15〜+20%） |
| 成長と季節性 | 2年間の流入の伸び（+15〜70%）、年周期の季節変動の大きさと位相、日々のばらつきの大きさ |
| 曜日 | 週末は流入が多く、火・水は少なめ |
| 毎年のイベント | ブラックフライデー（割引率もランダム）、新年キャンペーン、夏のセール、iOS の新バージョン対応。発生有無・日付・効果の大きさがランダム |
| 単発のイベント | ストアのおすすめ掲載、インフルエンサー施策、Android版リニューアル、課金・決済障害（解約が急増）、オンボーディング改善（転換率が上がる）、月額の値上げ（MRRが一段上がり、解約が一時的に増える） |
| 予告なしのスパイク | 日によってまれに、理由の付かない流入や解約の小さな急増が起きる |
| 年額の更新期 | 最初のブラックフライデーの1年後に、年額プランの解約の波が来る |

イベントはグラフ上に番号つきの縦線で表示され、どの日に何が起きたかがわかります。

### データの項目

日次データは「日付 × OS × プラン」で1行です。

| 列 | 意味 |
| --- | --- |
| `date` | 日付（YYYY-MM-DD） |
| `platform` | `ios` / `android` |
| `plan` | `monthly`（月額 ¥980、値上げイベント後は改定後の価格） / `yearly`（年額 ¥9,800） |
| `new_subs` | 新規の有料契約数（トライアルからの転換＋直接購入） |
| `churned` | 解約数 |
| `trial_starts` | 7日間トライアルの開始数 |
| `trial_conversions` | トライアルから有料に転換した数（7日前の開始数がもと） |
| `active` | その日の終わりの有効サブスク数 |
| `mrr` | 月次経常収益（円）。年額は12で割って月額換算 |

### 指標の定義

- **MRR**：期間末日の `mrr`。年額は12で割った月額換算。
- **月次解約率**：期間中の解約数 ÷ 期間中の平均有効サブスク数を、30日あたりに換算。
- **トライアル転換率**：期間中の有料転換数 ÷ トライアル開始数。
- **期間開始比**：有効サブスク・MRRを、期間に入る前日の値と比べたもの。
- **前期間比**：新規・解約・転換率を、同じ長さの直前の期間と比べたもの。

## API

| パス | 内容 |
| --- | --- |
| `GET /api/data` | 生成済みの全データ（`meta`、`rows`、`events`）を JSON で返す |
| `GET /api/meta` | シード、生成日時、期間、行数、イベント数 |
| `GET /api/raw.csv` | 日次データを CSV で返す。`platform`、`plan`、`from`、`to`（YYYY-MM-DD）で絞り込み可 |
| `GET /api/events.csv` | イベント一覧を CSV で返す |

例：

```bash
curl "http://localhost:3000/api/raw.csv?platform=ios&plan=yearly&from=2026-10-01"
```

## ファイル構成

```
server.js           ローカルサーバ。起動時にダミーデータを生成し、画面と API を返す
src/generate.js     ダミーデータの生成（シードつき乱数）
public/index.html   画面の HTML
public/app.css      見た目（ライト／ダークの両テーマ対応）
public/app.js       集計とグラフ描画、生データ表示
public/vendor/      d3 v7.9.0（同梱しているのでオフラインでも動く）
```

## 変更履歴

### 1.1.0

- **起動ごとのダミーデータ生成**：データを固定のファイルから、`npm start` のたびにサーバ側で生成する方式に変更しました。`SEED` を指定すれば同じデータを再現できます。
- **ダミーデータのランダム化**：ベースの水準、成長率、季節性、ばらつき、イベントの発生有無・日付・強さを毎回ランダムにしました。理由の付かない小さなスパイクも、まれに入ります。
- **生データの表示**：「生データ」タブを追加しました。日次データとイベントを表で表示し、絞り込み・並べ替え・日付検索・ページ送り・CSV ダウンロードができます。
- 画面に、使っているシードと生成日時を表示するようにしました。
- d3 を CDN から読み込むのをやめ、`public/vendor/` に同梱しました。

### 1.0.0

- 最初の版。有効サブスク数・新規・解約・MRR・トライアル転換のダッシュボード（固定のサンプルデータ）。
